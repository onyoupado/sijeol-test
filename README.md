# 그 시절, 나는 누구였을까

1910–1945, 실제 기록에 남은 장면 앞에서 고르다 보면 일제강점기를 산 사람들 36가지 얼굴 가운데 하나가 나오는 성향 테스트입니다.

- 제1부(공통 5문항)에서 입장이 정해지고, 제2부(입장별 5문항)에서 수단과 무대가 정해지며, 마지막 갈림길에서 가장 가까운 두 유형 중 하나를 고릅니다.
- 결과는 인스타그램 스토리 크기(1080×1920) 기록카드 이미지로 저장하거나 바로 공유할 수 있습니다.
- 서버나 빌드 과정이 필요 없는 HTML 파일 하나로 되어 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 테스트 본체 |
| `og.png` | 카카오톡·인스타그램 등에 링크를 붙였을 때 보이는 미리보기 이미지 |
| `README.md` | 이 문서 |

## 문항·유형 고치는 법

`index.html`을 메모장이나 VS Code로 열어 다음 부분을 고치면 됩니다.

- `const T=[` : 36가지 유형 (코드, 한자, 이름, 설명, 그 시절 기록)
- `const COMMON=[` : 제1부 공통 문항
- `const BR={` : 제2부 입장별 문항 (R 저항, M 경계, C 협력)
- `const PAIR=` : 유형별 동지·천적

## 주의

재미로 보는 테스트입니다. 실존 인물이나 그 후손에 대한 평가가 아니며, 기록 한 줄은 널리 알려진 역사적 사실을 짧게 줄인 것입니다.
